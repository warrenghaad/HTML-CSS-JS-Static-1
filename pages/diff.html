Engine Overview

The Diff Engine compares snapshots against the desired system state. It identifies gaps and chunks them into context-window-sized pieces for function agents.

Inputs: Snapshot JSON, Desired State Spec
Outputs: Chunked task list for Ag_Func agents

Tool List

Tool Status Function Input Output
Schema Comparator Healthy Compares current vs desired schemas Two schema definitions Schema diff object
Task Chunker Healthy Breaks diff into agent-sized tasks Full diff object Task queue
Context Splitter Error Ensures tasks fit context window Task + context limit Sized task chunks

Workflow Connections

← Receives from: Snapshot Engine
→ Outputs to: Ag_Func Engine

Task Chunking Rules

  • Each chunk must be ≤ context window size minus memory reserve
  • Each chunk must have defined input and output for independent testing
  • Chunks must be self-contained (no external dependencies within chunk)
  • Chunk boundaries should align with logical function boundaries
