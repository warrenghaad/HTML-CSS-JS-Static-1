Engine Overview

The Snapshot Engine captures the current state of your backend system. It creates immutable records that can be compared against desired states to generate task diffs.

Inputs: Backend API endpoints, Database schemas, File structures
Outputs: Snapshot JSON files with version IDs

Version Control Healthy Assigns version IDs, tracks history Raw state object Versioned snapshot

Workflow Connections

→ Outputs to: Diff Engine

When a snapshot completes, it is automatically sent to the Diff Engine for comparison against the desired state.
