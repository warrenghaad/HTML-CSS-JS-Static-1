1

HTML Structure: Building Cards

Beginner

Learn how HTML creates the structure of web pages using semantic elements.

Concept: HTML Elements

HTML uses tags to create elements. Each card on our diagram is made of nested elements:

<div class="engine-card">
  <div class="card-header">
    <span class="health-indicator healthy"></span>
    <h3>Knowledge Graph Engine</h3>
  </div>
  <p class="card-desc">Description text...</p>
  <div class="tool-list">
    <div class="tool">...</div>
  </div>
</div>
Key Takeaway: HTML is about structure. The <div> element groups content, <h3> creates headings, and <p> creates paragraphs.

CSS Flexbox: Arranging Cards in Rows

Beginner

Use CSS Flexbox to arrange elements in flexible rows and columns.

Concept: Flexbox Layout

Flexbox makes it easy to align items in a row or column:

.pipeline-row {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 1.5rem;
}

.engine-card {
  flex: 1;
  min-width: 0;
}
Key Takeaway: display: grid creates a grid layout. repeat(4, 1fr) makes 4 equal columns. gap adds space between items.

CSS Variables: Theme Colors

Intermediate

Use CSS custom properties (variables) to create consistent, reusable colors.

Concept: CSS Custom Properties

Variables let you define values once and reuse them everywhere:

:root {
  --bg: #0f1420;
  --accent: #7dd3fc;
  --healthy: #86efac;
  --warning: #fde68a;
  --error: #fca5a5;
}

.health-indicator.healthy {
  background: var(--healthy);
  box-shadow: 0 0 8px var(--healthy);
}
Key Takeaway: Define colors in :root using --name syntax. Use them anywhere with var(--name). This makes changing themes easy!
4

JavaScript Events: Theme Toggle

Intermediate

Make pages interactive by responding to user clicks and other events.

Concept: Event Listeners

JavaScript can respond when users interact with the page:

const themeToggle = document.getElementById('themeToggle');

themeToggle.addEventListener('click', function() {
  document.body.classList.toggle('light');
  localStorage.setItem('theme', 
    document.body.classList.contains('light') ? 'light' : 'dark'
  );
});
Key Takeaway: addEventListener('click', ...) runs code when an element is clicked. classList.toggle() adds or removes a CSS class. localStorage remembers settings.
5

CSS Transitions: Smooth Animations

Beginner

Add smooth animations when elements change state.

Concept: CSS Transitions

Transitions animate changes smoothly instead of jumping:

.engine-card {
  transition: all 0.2s;
}

.engine-card:hover {
  background: var(--bg-card-hover);
  transform: translateY(-2px);
}
Key Takeaway: transition: all 0.2s makes any change take 0.2 seconds. Combined with :hover, you get smooth effects when users mouse over elements.
6

JavaScript DOM: Finding and Changing Elements

Intermediate

Use JavaScript to find HTML elements and modify them dynamically.

Concept: DOM Manipulation

The DOM (Document Object Model) lets JavaScript access and change HTML:

function updateHealth(engineId, status) {
  const card = document.querySelector(`[data-engine="${engineId}"]`);
  if (card) {
    const indicator = card.querySelector('.health-indicator');
    indicator.className = 'health-indicator ' + status;
  }
}
Key Takeaway: querySelector() finds elements using CSS selectors. className changes an element's classes. This lets you update the page without reloading.
7

Responsive Design: Mobile-Friendly Layouts

Intermediate

Make your design adapt to different screen sizes using media queries.

Concept: Media Queries

Media queries apply different styles based on screen size:

@media (max-width: 1000px) {
  .pipeline-row {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 600px) {
  .pipeline-row {
    grid-template-columns: 1fr;
  }
}
Key Takeaway: @media (max-width: ...) applies styles only when the screen is smaller than that width. This lets you stack cards on mobile devices.
8

Multi-Page Apps: Navigation with Links

Beginner

Create multi-page applications with proper navigation and file organization.

Concept: File Organization

Organize files in folders and link between pages:

Project Structure:
├── index.html          (home page)
├── styles/
│   └── main.css        (all styles)
├── scripts/
│   └── main.js         (all JavaScript)
└── pages/
    ├── knowledge-graph.html
    ├── rwi-system.html
    └── lesson-builder.html

Linking from index.html to a page:
<a href="pages/knowledge-graph.html">View Details</a>

Linking back from a page to index:
<a href="../index.html">← Back to Diagram</a>
Key Takeaway: Use ../ to go up a folder level. Keep styles and scripts in dedicated folders. This keeps your project organized as it grows.
