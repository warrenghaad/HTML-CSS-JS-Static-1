System Functionality Document (SSOT)

Master reference defining what each engine does, the rules agents follow, and how data moves through the pipeline. This document governs all system behavior.

Pipeline Overview

Governance (this page) sets context for all engines
        ↓
Knowledge Graph Engine → ingests raw content, builds tagged ontology
        ↓
RWI System → researches, writes, and generates visual content
        ↓
Lesson Builder → assembles content into structured lessons
        ↓
Teacher/Student Facing → delivers final materials, collects feedback
        ↓
Feedback Loop → performance data flows back to Knowledge Graph

Engine 1: Knowledge Graph Engine

FunctionInputOutputAgent Rules
PDF Ingestion Raw PDFs (30GB+) Extracted text chunks with metadata Must preserve source reference for every chunk
Web Crawling URLs, search queries Scraped content with source attribution Respect robots.txt; store raw + cleaned versions

FunctionInputOutputAgent Rules

Feedback Loop Performance data Insights sent back to Knowledge Graph Flag underperforming topics for re-research

Global Agent Rules

  1. Visual-First: Every piece of content must have an accompanying image — no exceptions
  2. Source Traceability: Every fact, concept, or claim must trace back to an ingested source
  3. SSOT Compliance: All tagging, standards, and domain references must come from the registries on this page
  4. No Orphan Content: Every wiki node must connect to the graph; no standalone content allowed
  5. Incremental Updates: Agents update existing data — never wipe and rebuild
  6. Validation Required: No engine can mark output as "complete" without downstream validation
  7. Feedback Priority: Underperforming topics flagged by analytics get priority re-processing
