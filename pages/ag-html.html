Engine Overview

The HTML Test agent reads updated status files, performs validation tests, and writes results. This is the decision point for the pipeline split.

Inputs: Status files from Ag_Mess
Outputs: Test results → triggers next cycle or debug loop

Tool List

Tool Status Function Input Output
File Validator Healthy Validates file structure and content File from Ag_Mess status Validation report
Test Runner Healthy Runs input/output tests on chunks Chunk + test spec Test results
Result Writer Healthy Writes test results, triggers next step Test results Result file + signal

Workflow Connections

← Receives from: Ag_Mess Engine
→ Loop back to: Snapshot Engine (on success)

Pipeline Split Logic

IF PASS:
  1. 2a. Create new Snapshot
  2. 2b. Assess diff against next goal
  3. 2c. Generate JSONs for Ag_Func
  4. 2ci. Write "completed" file
  5. 2cii. Start next task
IF FAIL:
  1. Log failure details
  2. Notify Ag_Func of required fixes
  3. Re-enter Ag_Func → Ag_Mess → Ag_Html loop
  4. Continue until pass or manual intervention
