Engine Overview

Function agents receive chunked tasks and write new files. They are forbidden from claiming completion immediately after writing—they must wait for validation from downstream agents.

Inputs: Chunked task from Diff Engine
Outputs: New files + status report (pending validation)

Tool List

Tool Status Function Input Output
File Writer Healthy Writes new files based on task spec Task chunk + file spec Written file path
Status Reporter Warning Generates status report for Ag_Mess Write result Status JSON (pending)
Wait Handler Healthy Holds completion until validated Status + validation signal Final completion flag

Workflow Connections

← Receives from: Diff Engine
→ Outputs to: Ag_Mess Engine

Completion Rules

FORBIDDEN: Claiming task complete immediately after file write

Required sequence:
  1. Write file(s)
  2. Generate status report (status: "pending_validation")
  3. Wait for Ag_Mess to read and confirm
  4. Wait for Ag_Html to test and validate
  5. Only then mark as "complete"
