# RESEARCH → SECTION MAPPING

## Critical Framework: How Research Feeds Curriculum

**Core Principle:** Every piece of research produced in Stage 1 must explicitly map to one or more curriculum sections. This is not optional—it's how we prevent "orphaned research" that never reaches students.

### Day A Section Dependencies (Metaphor Track)

| Section | Research Inputs | Output Type |
|---------|-----------------|-------------|
| **A1: Myth Retelling** | Mythology Specialist Agent → primary myths featuring element | 600-800 word narrative |
| **A2: SEL + Metaphor** | Mythology Specialist + Academic Research → emotional parallels | Student connection prompt |
| **A3: Iconographic Art** | Museum Database + Academic Research → deity iconography | Visual analysis of symbolic features |
| **A4: Semiotics (MULTI-PART)** | **A4 Material Culture Specialist** → categorized artifacts across 6 domains | 2-4 sub-sections, each ~250 words |
| **A5: Technique/Design** | Academic Research → making methods OR motif classification | Process or pattern analysis |
| **A6: Activity** | Technique research → hands-on replication steps | Step-by-step instructions |
| **A7: Bridge** | Museum Database → civic artifact with unrevealed function | Question + artifact image |

### Day B Section Dependencies (Function Track)

| Section | Research Inputs | Output Type |
|---------|-----------------|-------------|
| **B1: Bridge Review** | Same civic artifact from A7 | Function reveal + diagram |
| **B2: Math Proof** | Academic Research → mathematical properties | Verification demonstration |
| **B3: Transformation** | Mathematical Research → property in motion | Operation explanation |
| **B4: Mechanics** | Mathematical + Innovation Research → physical results | Cause-effect chain |
| **B5: STEM History** | Academic Research → historical contributions | Field context |
| **B6: The Moment** | Innovation Research → specific breakthrough | Invention narrative |
| **B7: Activity** | Engineering/Innovation → build/test procedure | Construction steps |
| **B8: Exit Ticket** | All Day A + B research → synthesis | Unification statement |

### A4: THE INSTITUTIONALIZATION SECTION (Critical Focus)

**A4 is the heart of Day A's cultural analysis.** It demonstrates how the geometric element—originally a divine/mythic symbol—became internalized and institutionalized across all levels of Mesopotamian society. 

**Why A4 Matters:**
- A1-A3 establish the element's divine origin and visual vocabulary
- **A4 shows how that vocabulary spread through society** (sacred → civic → domestic → personal)
- This is the "diffusion" moment—from temple to marketplace to home
- Without strong A4, students see geometry as "temple stuff" rather than embedded cultural language

**A4 Multi-Part Structure (per SSOT-002):**
```
A4a: Sacred/ceremonial objects → divine significance
A4b: Ritual context → ceremonial significance  
A4c: Official/administrative → authority markers
A4d: Domestic/everyday → daily significance
A4e: Architectural elements → spatial significance
A4f: Personal/wearable → individual significance
```

**A4 Research Requirements:**
- Each sub-section needs **1 specific named artifact** (not "objects" plural)
- Each sub-section identifies a **different semiotic function**
- Each sub-section represents a **different social context**
- Total A4 target: ~1000 words across 2-4 sub-sections

**Validation (from SSOT-002):**
```
BLOCKED IF:
- A4 contains only 1 sub-section
- A4 sub-LOs cite same artifact category
- A4 sub-LO says "appears on objects" (plural)
- A4 sub-LOs repeat same semiotic function
```

## 3. PRIORITY ASSIGNMENT

### CRITICAL Priority
- First image in a section (sets visual tone)
- Primary artifact that entire section analyzes
- Key diagram that teaches core mathematical concept
- Myth storyboard that introduces geometric metaphor

### HIGH Priority
- Supporting artifacts that reinforce main concept
- Multi-step diagrams that show procedures
- Comparison images that highlight differences

### MEDIUM Priority
- Contextual images that enrich understanding
- Alternative examples of same concept
- Detail shots of already-featured artifacts

### LOW Priority
- Optional enrichment images
- Decorative or atmospheric images
- Redundant examples

```python
def assign_priority(image_need):
    """
    Logic for priority assignment.
    """
    priority_score = 0
    
    # Section position
    if image_need['section_number'] <= 2:
        priority_score += 3  # Early in lesson
    
    # Pedagogical function
    if 'primary concept' in image_need['pedagogical_function'].lower():
        priority_score += 3
    
    # Category
    if image_need['category'] in ['storyboard_illustration', 'mathematical_diagram']:
        priority_score += 2  # Creation takes time
    
    # Uniqueness
    if image_need['is_unique_to_this_lesson']:
        priority_score += 2
    
    # Dependencies
    if image_need['blocks_other_sections']:
        priority_score += 2
    
    # Assign priority
    if priority_score >= 8:
        return "critical"
    elif priority_score >= 5:
        return "high"
    elif priority_score >= 3:
        return "medium"
    else:
        return "low"
```
