# SSOT-000: Master Taxonomy & Tagging Standard (FINAL)

This SSOT is the **stable truth** every tool, agent, watch-folder, UI panel, and downstream deliverable should rely on.

It does **three** things:

1) Defines the **canonical meanings** of your taxonomy terms (GEA/GEM/GEK/GEpHR/GEU, etc.)  
2) Defines a **tagging grammar** (IDs, tags, alias expansion, forbidden shortcuts)  
3) Defines a **production contract**: how sections become evidence → artifacts → deliverables

---

## 0) Non‑negotiable guardrails (the stuff we stop arguing about)

### 0.1 GEpHR is **Metaphor**
- **GEpHR = metaphor / meaning / semiotics / cognitive scaffolding**.
- It is **not** “philosophy,” “humanistic,” “SEL,” “phenomenology,” or any invented expansion.
- Day A is GEpHR territory: meaning is *established, visualized, internalized, institutionalized*.

### 0.2 GEK is **Conceptual (Math + Science)**
- **GEK = mathematical/scientific conceptual elements** (your Day B conceptual spine).
- Math-only is *too narrow*; science belongs here too.

### 0.3 No forced causality between Day A and Day B
- Day A and Day B are **parallel lenses** on the same geometric element.
- They can **correct**, **reinforce**, and **challenge** each other, but we do **not** encode a forced causal chain.

### 0.4 No single-letter tags (ever)
- Tags like `"e"` are **banned**.  
- If you want short codes, use *namespaced* short codes: `stem.e`, `get.te`, etc.

---

## 1) The “taxonomy of taxonomy” model (how things nest without trapping you)

Your system is best modeled as **orthogonal facets**, not a single strict tree.

- **Form facet**: what it *is* in geometry (GEA/GEM)
- **Meaning facet**: what it *signifies* in culture (GEpHR)
- **Concept facet**: what it *proves/quantifies/explains* (GEK)
- **Operator facet**: what you *do to/with* the form (transformations, dimensional mapping)
- **Domain facet**: where it sits in knowledge practice (math, astronomy, materials, engineering…)
- **Artifact facet**: how it becomes visual curriculum (image types, scene types, media outputs)
- **Evidence facet**: the distillation spine (conclusion ↔ evidence graph)

This gives you flexibility **without** trying to classify the entire universe.

## 2) Canonical taxonomy definitions (GE*)

### 2.1 GE (Geometric Element)
A **geometric throughline** — either a platonic form or an intentionally curated spatial mapping that is central to meaning/function.

### 2.2 GEA (Atomic)
Irreducible primitives: point, line, angle, arc, circle, triangle, etc.  
**Rule**: if you remove any component, it ceases to be itself.

### 2.3 GEM (Molecular)
Any form built from **2+ atomic elements** or atomic elements + a rule of composition (repeat, symmetry, interlace, tessellate, etc.).  
Examples: rosette, grid, wheel+axle, truss, tessellation.

### 2.4 GEK (Conceptual)
Mathematical + scientific concepts expressed through geometry.  
Examples: symmetry, area, torque, pressure distribution, stability, flow, periodicity, parallax.

### 2.5 GEpHR (Metaphor)
The **meaning-making scaffold**: mythic definition, symbolic rendering, semiotics on objects, ritual internalization, aesthetic institutionalization.  
GEpHR does **not** imply “before measurement.” It is a **co-equal lens**.

### 2.6 GEU (Ubiquitous)
A **flag** meaning “this motif/composition is cross-cultural (3+ civs).”  
GEU does not replace GEA/GEM; it annotates them.

### 2.7 Operators (Transformations + Representation)
Operators are not “elements.” They are **verbs**.

- **Transformations** (movement/operation): rotate, translate, reflect, scale, shear, extrude…  
- **Representation / dimensional mapping**: 3D→2D projection, 2D→3D extrusion, 1D-on-3D decoration, etc.

Canonical namespaces:
- `op.*` for transformations
- `rep.*` for dimensional mapping

## 3) Day A / Day B section contract (canonical meanings)

### Day A (GEpHR): Metaphor track
- **A1 Myth Definition (Myth Video)**: establish the element’s meaning in narrative form.
- **A2 Metaphor Visualization**: show the element as an attention anchor (no SEL language).
- **A3 Mythic Iconography**: show the element in deity/myth art conventions.
- **A4 Material Culture + Ritual**: show the element embedded in objects, practices, and ritual life.
- **A5 Decomposition (Style/Technique)**: teach how the culture renders the metaphor visually.
- **A6 Art Activity**: student practice: signify the metaphor with precision.
- **A7 Bridge Prompt**: a question anchored in a **real structure/object** that also sets up Day B.

### Day B (GEK): Function track
- **B1 Bridge Answer**: same structure/object; reveal the functional role of the element.
- **B2 Math Concept**: the geometric property in conceptual/quantitative form.
- **B3 Science Effect**: what the math enables in the real world (forces, motion, flow, etc.).
- **B4 STEM Timeline (Discovery → Innovation → Invention)**: history of the concept/effect in use.
- **B5 Case Study (The Moment)**: one focused invention/problem with evidence.
- **B6 Deconstruction**: break the invention into geometric components + operators + materials.
- **B7 Build/Design Challenge**: hands-on project.
- **B8 Synthesis**: short wrap-up / explanation artifact.

## 4) Evidence distillation (CAR without p>qiffw)

### 4.1 Rule
- Every atomic content unit (sentence, bullet, caption) is either:
  - a **Conclusion (C)**, or
  - **Evidence (E)** supporting a parent conclusion.

### 4.2 Graph
- Conclusions can support higher-level conclusions.
- Evidence can have evidence (sub-evidence).

This makes your “fractal deliverables” possible:
- **Teacher Summary**: section-level conclusions + 1–5 artifacts each
- **Slides**: teacher-summary conclusions → captions
- **Student worksheet**: slide conclusions → prompts/tasks
- **Etextbook**: all evidence + all artifacts + all sources

## 5) Canonical tag grammar

### 5.1 IDs (stable)
- Lesson: `lesson.<civ>.<deity>.<element>.<week>`
- Section: `sec.A1` … `sec.B8`
- Artifact: `art.<lesson_id>.<sec>.<artifact_type>.<nn>`
- Claim: `clm.<lesson_id>.<sec>.<nn>`
- Source: `src.<provider>.<slug>`

### 5.2 Tags (faceted; dot notation)
Minimum required tags per section pack:

- `sec.*` (section code)
- `civ.*`
- `deity.*` (or `myth.*` where deity-less)
- `ge.element.*` (human-readable element label)
- **one** of: `gea.*` / `gem.*`
- **Day A**: `gephr.*` required  
- **Day B**: `gek.*` required  

Optional but recommended:
- `op.*` (transformations)
- `rep.*` (representation mapping)
- `dom.*` (knowledge domain)
- `img.*` (image types / scene types)
- `src.*` (sources)

### 5.3 Alias expansion (compat)
Your system should accept legacy tags and expand them:

- `#GEA/circle` → `gea.circle`
- `elem.circle` → `gea.circle` **and** `ge.element.circle`
- `GEK-T` / `GEOK-T` → `op.*` (operator facet)
- Single letters are rejected (see guardrail 0.4)

---

## 6) Invention composite schema (how inventions “converge” without losing the mix)

Inventions are *composites* by nature. Track them as a bundle:

- **Geometry bundle**: components (GEA/GEM), their roles, and local features
- **Operator bundle**: what’s happening (rotation, translation, etc.)
- **Material bundle**: materials + constraints
- **Function bundle**: what problem it solves
- **Evidence bundle**: sources + claims that justify each part

(See SSOT‑000 JSON for the exact schema.)

---

## 7) Deliverable minimums (hard floor)
No deliverable is valid if a section has **zero** artifacts.

- Each section must have **≥ 1 artifact + 1 evidentiary statement**.
- Target range: **3–5 artifacts/section** (section-dependent).
