# SSOT-008: GUARDRAILS (Non-destructive automation)
version: 5.0.0
generated_at: 2026-02-02

## Absolute invariants
### File-system invariants
- **NO DELETE** (no rm, no unlink, no destructive operations)
- **NO OVERWRITE** (write-new only; if updating, create a copy with a new filename)
- **NO DIRECT WRITES TO CANON** (CANON is read-only)
- All automation outputs go to **WORKSPACE/**

### Tag invariants
- **NO SILENT TAG REMOVAL**
- Any “removal” must be emitted as **suggested_removal** in a patch, never applied automatically
- Unknown tokens preserved as `novelty.raw.*`
- Deprecated tokens preserved as `deprecated.raw.*`
- Single-letter tokens: **flag-only**, never removed

### Execution gating
- Any engine must pass **TEST_INGEST** before it can be used on real content.
- Engines must produce: run receipt + qa_report + patches.
