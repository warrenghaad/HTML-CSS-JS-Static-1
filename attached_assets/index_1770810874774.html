What this is

This folder is a lightweight “don’t-miss-a-step” process tracker for converting the 2‑month Grade 3/4/5 Mesopotamia pilot markdown into complete, image-rich, navigable lesson files. Each grade board is pre-populated with cards for sections that include an Artifacts block (cards: Grade 3 = 78, Grade 4 = 91, Grade 5 = 38).

Core pipeline (the “golden path”)

  1. Normalize the markdown: consistent headings for Week / Day / Section, and consistent artifact formatting.
  2. Chunk to lesson units: decide your output granularity (one HTML per grade, or per week, or per day).
  3. Artifact QA: ensure every artifact has (a) a clear name, (b) source, (c) specs, (d) where it appears.
  4. Assets + rights: pull images, write captions and attributions, store locally in an assets/ folder.
  5. Build: convert MD → structured JSON → render into the HTML shell.
  6. QA + publish: run link checks, image loading, keyboard navigation, and alt text review.

How to use the Kanban

  • Open a grade board and drag cards across columns as you complete work.
  • Use the per-card checklist to make sure you don’t skip “assets + alt text + render checks”.
  • Filters (Week/Day/Search) help you focus on one slice at a time.
  • Everything saves locally in your browser.
