Chapter 1: Introduction to Web Design

Lesson 1.1: What is HTML?

HTML (HyperText Markup Language) is the standard language for creating web pages. It describes the structure of a webpage using elements and tags.

Example:

<h1>This is a heading</h1> <p>This is a paragraph</p>

Lesson 1.2: Understanding CSS

CSS (Cascading Style Sheets) is used to style and layout web pages. It controls colors, fonts, spacing, and positioning.

Example:

h1 { color: blue; font-size: 24px; }

Chapter 2: Making Pages Interactive

Lesson 2.1: JavaScript Basics

JavaScript adds interactivity to your web pages. You can respond to user actions like clicks, create animations, and update content dynamically.

Example Code:

function greet() { alert('Hello, Student!'); }
